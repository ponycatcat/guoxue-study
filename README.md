# 國學常識通

國中國文「國學常識」學習網 —— 六書、韻文流變、經典古籍、應用文與稱謂，附隨堂測驗。

🔗 **線上瀏覽:** https://ponycatcat.github.io/guoxue-study/

## 內容

| 主題 | 涵蓋範圍 |
|---|---|
| 文字・分類 | 六書、經史子集四部分類法 |
| 韻文流變 | 詩經 → 楚辭 → 賦 → 樂府 → 近體詩 → 詞 → 曲，含 4 張比較表 |
| 散文・小說 | 古文運動、唐宋八大家、小說演進、四大古典小說 |
| 經典古籍 | 十三經、四書五經、史書五體例、史記 vs 漢書 |
| 稱謂・應用文 | 書信結構、柬帖題辭、年齡稱謂、謙敬詞 |
| 文學之最 | 之祖之最、詩人雅號、重要合稱 |
| 隨堂測驗 | 24 題單選，即時作答與詳解、計分 |

## 使用方式

單一 HTML 檔，無需建置或安裝。直接開啟 `index.html`，或造訪上方線上網址。支援深／淺色切換與手機瀏覽。
